# Snowаfall

Нативное приложение для macOS 14+: снег поверх рабочего стола и обычных окон.
Swift · AppKit · SwiftUI · Core Animation. 

## Функционал

- Снежинки разных размеров, прозрачности и скорости, с ветром и колебаниями.
- Скорость и ветер меняются плавно без перезапуска снега; интенсивность — постепенно.
- Прозрачный overlay пропускает клики и не забирает фокус.
- Меню ❄️: включение, интенсивность, скорость, ветер, настройки и выход.
- Сохранение параметров, поддержка нескольких мониторов и Retina.
- Остановка анимации при сне экрана; приложение скрыто из Dock.

**Пока не реализованы:** столкновения с окнами, сугробы, очистка снега и автозапуск.
Поведение в полноэкранных Spaces и 60 FPS ещё не проверены.
`fullScreenNone` ограничивает режим самого overlay, но не гарантирует скрытие
поверх любого полноэкранного приложения.

## Архитектура

Один target, компоненты сгруппированы по ответственности:

| Папка | Назначение |
|---|---|
| `App` | `MyApp` — запуск; `AppCoordinator` — жизненный цикл и связывание компонентов |
| `Snow` | `Snowflake` — модель; `SnowEngine` — движение и сглаживание параметров; `SnowRenderer` — отображение |
| `Overlay` | `OverlayWindowManager` — прозрачные окна на мониторах |
| `Settings` | `SettingsManager` — параметры; `SettingsView` — интерфейс SwiftUI |
| `MenuBar` | `MenuBarController` — управление через строку меню |
| `Resources` | `Assets.xcassets` — графические ресурсы |

Меню и настройки используют общий `SettingsManager`.
`AppCoordinator` передаёт параметры через `OverlayWindowManager` в `SnowRenderer`.
На каждом экране renderer обновляет свой `SnowEngine` через display link и отображает
частицы слоями Core Animation. При изменении настроек окна и частицы сохраняются.

## Как запустить

1. Откройте `Snowfall.xcodeproj` в Xcode.
2. Выберите схему **Snowfall** и устройство **My Mac**.
3. Нажмите **⌘R** — снег включится сразу.
4. Управляйте приложением через **❄️ в строке меню**.

Используется локальная подпись **Sign to Run Locally**.
Разрешения Accessibility и Screen Recording для текущего MVP не нужны.

Проверено программно: непрерывность частиц при смене параметров, действия меню,
сохранение настроек, остановка/возобновление по уведомлениям и освобождение renderer.
Вручную остаётся проверить клики через снег, несколько мониторов,
реальный сон экрана, Spaces и полноэкранные приложения.
